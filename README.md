# Street Cleaners-

Sistema web full-stack desarrollado para el programa ADSO (SENA), orientado al seguimiento de micro-basureros satélite, reportes ciudadanos y gestión municipal.

## 🛠️ Stack Tecnológico
- **Frontend:** React.js
- **Backend:** Node.js / Express
- **Base de Datos:** MySQL
- **Control de Versiones:** Git y GitHub

## 📁 Estructura del Repositorio
- `street-cleaners-frontend/`: Interfaz de usuario en React.
- `street-cleaners-backend/`: API REST y lógica del servidor.
